Entry for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) competition on make.fun.

## About

A single-line tech support reply under 200 characters in which a cheerfully unhelpful support agent responds to a customer's live launch emergency by silencing the monitoring alerts instead of fixing the underlying outage.

## Run it

The program requires Node 22+ (no external dependencies) and writes the UTF-8 entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`). The grader executes it as `node /bot/main.ts`.

```sh
node main.ts
```

To test locally into a custom directory:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
